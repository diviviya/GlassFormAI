# Dataset Provenance

## Source

GlassFormAI uses the metallic-glass glass-forming ability dataset associated with:

R. M. Forrest and A. L. Greer,  
"Machine-learning improves understanding of glass formation in metallic systems",  
Digital Discovery, 2022, 1, 476–489.

DOI: 10.1039/D2DD00026A

Source repository:
https://github.com/Robert-Forrest/GFA

## Local Dataset

The locally used raw dataset is:

`data/raw/data.csv`

It contains alloy compositions and associated metallic-glass data, including:

- Composition
- Dmax
- GFA
- Tg
- Tx
- Tl

## Data Handling

The raw dataset is intentionally not committed to this repository.

It is kept locally for analysis, while this file records its provenance and source.

Users obtaining the dataset should comply with the applicable terms and conditions of the original source.

## Important Note

This dataset is associated with the Forrest and Greer (2022) work.

It is not claimed to be identical to the expanded dataset used in Liu et al. (2023).

The distinction between the source dataset and the datasets described in related publications will be maintained throughout the project.
